# Epic Relics 下一步完善计划

日期：2026-10-04

基线：Minecraft 26.3 / Epic Relics 0.3.0-beta+26.3

依据：当前 README、`RelicProgression` 实现及人工测试清单。

## 当前基础与本轮交付

当前已有六件遗物、六种探索印记、六条替代锻造路线和 26 项可见成就。重力之刃和双模式共鸣长弓已有立体模型，六条精通挑战已接入服务端成功事件。后续重点是让这些内容更可靠、更容易理解，并让精通成果有可见的回报。

**本轮交付范围包含盔甲外型重塑。** 以用户提出的“龙之研究龙套”为造型参考方向，采用已确认的黑紫主体与暗金镶边，改善龙角轮廓、胸肩比例、分层甲片与整套辨识度。参考其[经典盔甲的分部骨架结构](https://github.com/Draconic-Inc/Draconic-Evolution/blob/1.12.2/src/main/java/com/brandon3055/draconicevolution/client/model/ModelDraconicArmor.java)，为 Epic Relics 制作原生几何。此项由当前改型工作交付，不重复列入后续功能里程碑；具体外观与验证结果以本轮实际模型、实机截图及检查记录为准。

现有检查记录确认：构建和专服开发检查通过；旧版盔甲细节、武器模型、两种弓模式各三档拉弓画面、成就页与落点粒子已查看；虚空印记首次发放、持续满足条件不重复、重启后再次进入末地仍不重复已验证。这些记录不等于六条试炼、全部实战和多人场景均已验证，也不替代本轮新盔甲的实机检查。

## 持续遵守的设计约束

- 保留现有伤害、护甲、射程、冷却、固有附魔和按键语义；不加入套装属性加成。
- 保留原七条配方。印记路线仍是“对应印记 + 原对应基础装备 + 下界之星”；印记每玩家一次、可交易、锻造消耗，探索检查本身不扣除材料。
- 不恢复左侧常驻 HUD、技能面板、冷却条或距离/风险文字。采用短 actionbar、就绪音效、世界内粒子，以及玩家主动打开的说明页面。
- 保留虚空步精确 54 格眼部射线和原命中落点；预览用于提示，不自动更改落点。
- 每阶段单独交付、检查和记录。未做的实测保持未验证，不以编译成功代替玩法或视觉通过。

## 阶段一：可靠性与发布质量（P0）

**玩家价值：** 获得装备、释放技能和完成挑战的结果稳定可信，多人游玩不会丢进度、重复奖励或误伤队友。

| 工作包 | 具体工作 | 验收条件 |
| --- | --- | --- |
| 六条探索路线回归 | 补齐龙视、天翼、重核、重力、共鸣的真实获取；分别检查材料、地点和原版前置。覆盖两位玩家独立奖励、交易、满背包、死亡和重启。 | 每条路线记录一个成功例及适用的失败例；普通重复检测不再发放；两人可各得一枚；满背包奖励可取回；原配方和替代配方均能正常锻造。 |
| 技能与成就对齐 | 验证三档重踏、俯冲、重力场、暗箭和声波的实际命中，以及虚空步三维度与天翼连续滑翔计时。重点检查空放、免疫目标、队友、宠物和禁止 PvP 的玩家。 | 合法成功事件才计入对应挑战；空放或被拒绝的伤害/效果不计入；三档边界、死亡/脱甲/落地后的飞行计时符合现有规则；服务端重启后已完成进度仍在。 |
| 操作反馈与联机时序 | 检查改键、缺少装备、无箭、声波未拉满、连续按键及重登时冷却；对照实际虚空步落点检查粒子提示。 | V/R/G 与 Use Item 改键均有效；失败提示简短且不刷屏；拒绝施法不会重新开始冷却或多扣材料；没有常驻侧栏；原技能参数保持一致。 |
| 视觉兼容与发布包 | 对本轮盔甲进行行走、潜行、游泳、飞行、左右手和饰纹/附魔光效检查；检查弓完整拉放过程、粒子档位与多人同屏。 | 在原版 Fabric 客户端和两客户端专服场景完成核心检查；无缺贴图、明显穿模、持续残留粒子或旧资源混入。使用全新客户端或明确重载资源，并以新文件名保存截图。 |

交付物：修复后的候选包、对应提交的检查记录、已验证范围与未覆盖兼容性列表。Vulkan及第三方渲染模组分别记录，不默认宣称兼容。

**进入下一阶段的条件：** 奖励丢失/重复、错误伤害目标、无法正常锻造、持续崩溃等关键问题已解决；其它问题有明确复现记录与影响说明。

## 阶段二：探索节奏与获取回报（P1）

**玩家价值：** 第一次游玩就知道去哪里、准备什么、为什么值得去；完成探索后能清楚识别自己的成果。

| 工作包 | 具体工作 | 验收条件 |
| --- | --- | --- |
| 按需查看的遗物手册 | 用主动打开的手册呈现六件遗物、原配方/印记配方、准确试炼前置和技能使用示例。先做静态内容和已有成就进度展示。 | 玩家无需离开游戏即可查明对应本体、下界之星成本和试炼前置；清楚标出印记一次性奖励、可交易及锻造消耗；已用原配方取得遗物的玩家也能正常阅读，手册不成为制作门槛。 |
| 梳理现有三类探索主题 | 组织末地、试炼密室、深暗之域的目标说明；将已有六条材料线索与试炼、锻造结果连接起来。先用虚空与共鸣路线检验说明是否清楚，再推广到其余路线。 | 两名测试者能仅依照游戏内说明完成测试路线，并准确判断“材料不足”“地点不符”或“原版成就未完成”；不把父子成就连线或配方书解锁误解为强制制作限制。 |
| 让印记和故事可辨认 | 为六种印记设计各自的图标和简短背景片段；同步四件盔甲的背包图标，使其与本轮龙甲外型一致；在首次奖励时用一次短提示引导查看锻造用途，已获得内容留在手册中。 | 六种印记在背包缩略图中可区分；盔甲图标与穿戴外型能对应；中英文名称、描述与真实条件一致；奖励提示仅在首次完成时出现；重新登录不会重复弹出。 |
| 根据实际体验评估节奏 | 记录测试者从获得线索到满足条件、再到锻造的时间与卡点，重点观察重力路线的原版单次重锤 50 心条件，以及末地路线的多人材料分配。 | 形成一页明确的体验记录与下一批候选调整；本阶段先改善说明、发现顺序和反馈，既有配方、试炼条件与数值保持原样。 |

交付物：遗物手册、六枚印记图标、准确的路线说明及一轮探索体验记录。先采用现有原版地点和进度，不把新 Boss、大型建筑生成或自定义维度纳入这一阶段。

## 阶段三：可选精通与外观奖励（P2）

**玩家价值：** 集齐遗物之后仍有值得展示的目标，熟练使用技能可以留下个人风格。

| 工作包 | 具体工作 | 验收条件 |
| --- | --- | --- |
| 给现有精通添加首批外观奖励 | 复用已存在的六条精通进度，首批控制在两项，例如龙视冠饰配色与重力之刃符纹。先验证解锁和选择流程，再扩展到其它遗物。 | 完成对应挑战可解锁并预览外观；已在旧存档完成挑战的玩家能补领解锁；奖励不增加攻击、护甲、射程或冷却收益；原版外观始终可选。 |
| 主动选择与多人同步 | 在手册中提供外观选择和恢复默认；精通外观解锁按玩家保存，与可交易的探索印记规则分开说明。 | 玩家重登、死亡和服务器重启后保留自己的选择；另一位玩家能看到正确外观；装备交易不自动转移精通解锁；暗箭/声波模式仍能一眼区分。 |
| 小规模技巧挑战扩展 | 在现有挑战验证可靠后，选择少量操作目标，例如一次战斗中完成有效俯冲与重力场组合，或以两种弓模式分别成功命中。具体条件在该阶段再确定。 | 每项挑战能用一两句说明、服务器能可靠判断；不要求每日登录或机械累计大量击杀；不与现有精通重复；可在成就页或手册查看进度，不新增常驻 HUD。 |
| 外观性能与可读性 | 优先使用已有模型的可切换构件、配色和克制的短粒子，不让奖励遮挡队友视野。 | 双人同屏可区分装备和技能状态；低粒子设置有效；默认外观可恢复；旧世界载入正常；高负载问题有可重复场景与记录。 |

交付物：两项精通外观奖励、可靠的解锁存储和选择方式、旧存档迁移验证。外观系统稳定后再决定是否扩充奖励数量。

## 建议实施顺序

本轮盔甲改型交付后，先完成阶段一中“六条获取 + 两人独立奖励 + 满背包/重启 + 成功技能成就”的集中回归；随后交付阶段二的手册和印记辨识度；最后以两项外观奖励验证阶段三。每一步都对应玩家能看到的改进和可复核的验收记录。
