# Epic Relics

Epic Relics is a Fabric mod for Minecraft Java Edition 26.2.

It adds six unbreakable endgame relics with distinct armor, movement, melee,
area-control, and ranged abilities.

## Requirements

- Minecraft Java Edition 26.2
- Fabric Loader 0.19.3 or newer compatible release
- Fabric API 0.157.0+26.2
- Java 25

## Build from source

Use JDK 25 and the Gradle Wrapper:

```powershell
.\gradlew.bat genSources
.\gradlew.bat build
.\gradlew.bat runClient
```
